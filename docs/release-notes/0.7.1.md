## 0.7.1 新功能

### 📏 便签大小
- 便签有 **小 / 中 / 大** 三种大小：在编辑框底部选，或右键 →「大小」。
- 任务多、字多的便签换成中或大就能全部看到；大小会被记住。
- 绳子会给大便签留出更宽的位置，不会和旁边的便签挤在一起。

### 📝 长任务完整显示
- 任务文字太长时会自动换行，完整显示，不再被截成「…」。
- 便签上放不下的任务，会在最后显示「还有 N 项…」。

0.7.0 的新功能（圣诞风格、小任务清单、便签颜色等）见 [0.7.0 说明](https://github.com/yujiayan1016/string-journal/releases/tag/v0.7.0)。
