## 0.7.0 新功能

### 🎄 圣诞风格
- 菜单栏图标 → **风格** 里新增「圣诞」，和手帐、便利贴并列，随时切换，便签内容不变。
- **绳子**：麻绳缠满松枝花环，点缀尤加利叶、红浆果、丝绒红蝴蝶结和一闪一闪的暖光小灯，两端各系一大束松枝。
- **空着的绳段**：垂一串金色珠链，零星挂着圣诞球、圣诞帽、拐杖糖、姜饼人等小挂件，同一屏不重复。
- **便签**：一律用木夹子，有圣诞格子、邮票齿边礼物签、手绘双线框、鼠尾草绿条纹等多种样式。

### 🖼 配套圣诞桌面壁纸
- 切到圣诞风格时会问你要不要一起换上配套壁纸：墨绿底、飘雪、雪地小松树，按屏幕尺寸绘制。
- 切回其他风格时自动换回你原来的壁纸；如果你中途自己换过壁纸，就不动。

### ✅ 小任务清单
- 编辑框里点「新建任务」（或在任务里按 ↩、⌘N）就能加一项任务。
- 任务超过一项时，便签上会出现小方框，点一下划掉一项；全部划掉，整张便签自动完成。
- 编辑框里支持 ⌘C / ⌘V / ⌘X / ⌘A / ⌘Z。

### 🎨 便签颜色
- 编辑框底部可以选颜色，彩色圆点可以自定义任意颜色，「A」恢复跟随风格；右键 →「颜色」也能换。

### 🗑 删除便签
- 鼠标移到便签上，点左下角的垃圾桶，便签揉成纸团扔进程序坞的废纸篓；也可以直接把便签拖到废纸篓上，或右键 →「扔进废纸篓」。
- 废纸篓里会留一份同名 .txt，删错了还能看到内容。

### ✈️ 完成动画与任务历史
- 勾选完成后，便签盖上「完成」章，折成**纸飞机**飞进漂流瓶。
- 菜单新增「任务历史」：最近 15 天完成的任务，重启也不会丢，点一条可以重新挂回绳子。

### 👋 新手引导
- 第一次打开会弹出欢迎卡片，可以花一分钟跟着引导动手试一遍。
- 菜单里的「新手引导…」可以随时重走一遍，用单独的练习便签，不会动到你自己的便签。

### 🪢 手感调整
- 便签摆动更稳、更快停下；拖动时的甩动幅度有上限，挂着的便签不会歪得太厉害。
